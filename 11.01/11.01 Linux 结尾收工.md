# 今日学习笔记：Linux Bash 脚本入门

## 一、Bash 脚本基础
脚本三件套：#!/bin/bash（第一行声明解释器）+ 命令 + exit 0（可省略）
执行方式：bash 脚本.sh（推荐，省去权限问题）或 chmod u+x 后 ./脚本.sh
变量：赋值 a=1（等号两边不能有空格），取值必须加 $a 或 ${a}
代码块配对：if...fi、for...done（Python 靠缩进，bash 靠关键字收尾）

## 二、核心语法：for + if
for val in $CUR_DIR      # 按空格切分字符串当列表遍历
do
    if [ -f $val ]; then      # -f: 是文件？(os.path.isfile)
        echo $val >> filenames.txt
    elif [ -d $val ]; then    # -d: 是目录？(os.path.isdir)
        echo $val >> dirname.txt
    fi
done

[ ] 是 test 命令，括号内侧必须有空格
> 覆盖写，>> 追加写（相当于 Python 的 open(...,'w'/'a')）

## 三、重要概念：当前工作目录
[ -f ]、>、ls 等操作都相对于执行脚本时的目录
所以作业脚本里要先 cd bash_homework
输出文件生成在哪，取决于在哪一行敲的 bash xxx.sh
## 四、Docker 环境：宿主机 ↔ 容器传文件
共享文件夹：桌面/bioinfo_tsinghua_share/ ⇄ 容器内 /home/test/share/（实时同步）
进入容器：docker exec -it bioinfo_tsinghua bash
备用方案：docker cp 本地路径 容器名:容器内路径
⚠️ 别搞混：桌面上自建的 bash_homework/ 和共享目录里的 bash_homework/ 是两个文件夹

## 五、vim 新手避坑
操作	按键
撤销	Esc 后按 u（不是 Ctrl+Z！）
搜索	/关键词，n 跳下一个
保存退出	Esc → :wq
Ctrl+Z	是挂起程序到后台，恢复用 fg

## 六、写脚本的两种方式
电脑上用编辑器写好 → 存进 share 文件夹 → 容器里 bash 执行（方便，注意 Windows 换行 CRLF→LF）
容器里 vim 文件名 → i 编辑 → :wq 保存（练手）
一句话总结：编辑 → 保存（此刻才写入磁盘）→ bash 执行（从磁盘逐行读取）。
