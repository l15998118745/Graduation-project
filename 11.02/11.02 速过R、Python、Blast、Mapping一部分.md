# 生物信息学学习笔记（PART II 基础分析 & PART III 入门）

## 一、BLAST（PART II · 1.Blast）

### 章节关键点
- 建库：`makeblastdb -dbtype nucl -in <fa> -out <前缀>`（nucl 核酸 / prot 蛋白）
- 比对：`blastn -query <query.fa> -db <库前缀> -out <结果文件>`
- 蛋白互比可用 `-subject` 直接指定另一个 fasta

### 我的问题与解答

**Q1：怎么看比对结果？如何让结果在终端显示？**
- 不加 `-out` 参数，结果直接打印到终端
- 已保存的结果用 `less 结果文件` 查看，按 `q` 退出
- 推荐 `-outfmt 6`：输出紧凑表格（12 列：qseqid sseqid pident length mismatch gapopen qstart qend sstart send evalue bitscore），方便终端阅读

**Q2：阅读工具怎么退出？**
- `less` / `more`：按 `q`；less 中空格翻页、`b` 上翻、`/关键词` 搜索、`n` 下一个
- `vi/vim`：先按 `Esc`，再输入 `:q` 回车（强制不保存退出 `:q!`）

**Q3（作业2）：如何写 bash 脚本把蛋白序列随机打乱生成 10 个，再两两 blastp？**
- 核心命令：`echo $SEQ | fold -w1 | shuf | tr -d '\n'`（拆成单字符→打乱→重组）
- 两两循环：`for i in 1..10; for j in i+1..10; blastp -query shuf_$i.fa -subject shuf_$j.fa -outfmt 6`
- 结果解读：大多数配对无输出 = 随机序列间无显著同源；短 hit 多来自低复杂度区（如 SSSS），evalue 不显著
- 结论：BLAST 检测的是排列模式的同源性，而非氨基酸组成

## 二、GO 富集分析（PART II · 3.Function / 3.1.GO）

### 章节关键点
- 工具：geneontology.org 首页的 GO Enrichment Analysis（背后是 PANTHER）
- 输入：基因列表（支持 Ensembl ID，每行一个）；选物种 Homo sapiens
- 结果默认只显示 **FDR < 0.05** 的 GO term

### 核心概念（表格各列）
| 列 | 含义 |
|----|------|
| REF # | 参考基因组中注释到该 term 的基因数（K） |
| Input # | 我的基因中落在该 term 的个数（k） |
| expected | 期望命中数 = K × n / N |
| Fold Enrichment | 富集倍数 = 实际 / expected |
| raw P value | Fisher 精确检验原始 P 值 |
| **FDR** | 多重检验校正后 P 值，**显著性看这一列** |

### 我的问题与解答

**Q：怎么在网页里做并查看功能富集？**
- geneontology.org → Enrichment Analysis 输入框粘贴基因 ID → Launch → 跳转 PANTHER 结果页
- 实测 50 个基因富集在 DNA-templated DNA replication（14.1 倍）、DNA repair（7.6 倍）、nucleic acid metabolic process 等 → 该基因集主要参与 DNA 复制与核酸代谢
- 为什么用 FDR 而非 raw P：同时检验成千上万个 GO term，必须做多重检验校正

## 三、GSEA（PART II · 3.3.GSEA）

### 章节关键点
- GSEA 是一种**统计方法**（不同于 GO/KEGG 是数据库）
- 输入：①全基因按差异排序的 rank list（如 fold change）；②先验 gene set（GO/KEGG 注释或实验结果）
- 输出：ES、NES、P 值、FDR

### 我的问题与解答

**Q1：图 B 的 Gene Set S 是什么？**
- 一份先验的基因名单，如「DNA 复制相关基因」「p53 下游靶基因」，来自功能注释或其他实验
- 与 GO 富集的区别：不用预先挑显著基因，看整个 gene set 是否挤在排序表的顶端或底端

**Q2：ES 怎么计算？**
1. 全基因按差异排序
2. 沿排序表"走路"维护 running-sum：遇到 S 成员加上升增量（加权模式 ∝ |r|^p），非成员减 1/(N−N_S)
3. **ES = 曲线偏离 0 的最大幅度**（带符号）
   - ES > 0：S 富集在顶端（表型 A 高表达）
   - ES < 0：S 富集在底端
4. 显著性：随机打乱基因标签置换 1000 次得背景 ES → P 值；标准化得 NES；再算 FDR

### 文件格式
- `.rnk`：基因 ID + 排序值，两列
- `.gmt`：每行一个 gene set（第 1 列名字，第 2 列 label，其后为基因）；fGSEA 只兼容 gmt
- `.gmx`：每列一个 gene set，桌面版 GSEA 用

## 四、Mapping（PART III · 1.Mapping）

### 章节关键点
- 流程：fastq → 比对 → sam/bam
- fastq：每 4 行一条 read（@id / 序列 / + / 质量）
- sam（文本）vs bam（二进制压缩，推荐；可建索引 .bai 供 IGV 随机访问）
- unspliced 比对工具：bowtie / bowtie2 / bwa
- spliced 比对工具（真核 RNA-seq → 基因组）：STAR、HISAT2（需 gtf 注释）

### 我的问题与解答

**Q1：为什么 DNA-seq 和原核 RNA-seq 不需要考虑 splicing？**

| 数据类型 | 参考序列 | read 是否连续 | 需考虑 splicing？ |
|---|---|---|---|
| DNA-seq（任何物种） | 基因组 | 连续（基因组无剪接） | 否 |
| 原核生物 RNA-seq | 基因组 | 连续（无内含子） | 否 |
| 真核 RNA-seq → 转录组 | 转录本（已剪接） | 连续 | 否 |
| **真核 RNA-seq → 基因组** | 基因组（含内含子） | **断裂（跨外显子）** | **是，需 STAR/HISAT2** |

**Q2：解压 STAR 时一直问 replace ... [y]es/[n]o/[A]ll 怎么办？**
- 说明目录已解压过。输入 `A` 全部覆盖即可；或 Ctrl+C 取消，检查旧目录能否直接用

**Q3：STAR.mapping.tar.gz 这步还要做吗？**
- 要。`2.7.10a.zip` 是软件，`STAR.mapping.tar.gz` 是练习数据（fa/gtf/fastq），两者不同
- 检查：`ls data/` 有 tair10.Pt.fa 等文件则已解压过，可跳过

**Q4：文件只能下载到宿主机，怎么进容器的 mapping 目录？**
- 放共享目录 `/home/test/share` 后，在容器内：
  `cd /home/test/mapping && tar xvzf /home/test/share/STAR.mapping.tar.gz`
  （tar 可解压任意路径的压缩包，产物落在当前目录）
- 或 `cp` 到 mapping 再解压；容器能联网时也可以直接 `wget 链接`

**Q5：mapping、share 等章节目录之间能共享东西吗？**
- 能。它们只是同一容器文件系统里的不同目录，无隔离
- 跨目录调用：`/home/test/mapping/STAR-2.7.10a/bin/.../STAR --version`
- 复制：`cp` / `mv`；整目录 `cp -r`
- apt/R/pip 安装的软件装在系统路径，本来就全容器可用
- 章节目录独立只是组织约定：数据留在本章，大型工具可共用一份
